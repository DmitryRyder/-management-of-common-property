# Наш дом — демонстрация портала собственников

Интерактивное React-демо для дома: **Гомель, ул. Мазурова, 87**.

Демо: https://dmitryryder.github.io/-management-of-common-property/

## Возможности

- Обзор дома, смета, расходы и работы.
- Материалы собраний, опросы, сроки и напоминания.
- Обращения и смена статусов в роли председателя.
- Формирование образцов отчёта, уведомления и протокола; скачивание HTML и печать.
- Пример бухгалтерского кабинета и CSV-выгрузка.
- Схема портала, нормативные источники и макет видеонаблюдения.

## Демонстрационный режим

Все суммы, события, документы и обращения вымышлены. Иллюстрация не воспроизводит фактический вид здания. Действия сохраняются только в браузере посетителя. Переключение ролей служит для показа сценариев и не является авторизацией.

Уведомления не отправляются, реальные камеры, банк и бухгалтерские системы не подключены. Опрос не является юридически значимым голосованием. Документы — заготовки для демонстрации, требующие проверки перед реальным использованием.

В репозитории находится готовая статическая сборка. GitHub Pages публикует корень ветки `master`; `.nojekyll` отключает обработку Jekyll.
